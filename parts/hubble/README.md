# Hubble Optical Tube part

A full-scale (13.2 m x 4.2 m) Hubble Space Telescope main tube as a KSA
editor part, shipped with the Oh My Stars mod. Modeled after NASA reference
schematics and NASA's official GLB models: light shield with hoop ribs,
forward shell, 12-sided faceted equipment section, aft shroud, and the
spade-shaped aperture door standing open on its hinge brackets in the
deployed position. The tube is hollow back to a dished primary mirror, with
the secondary mirror barrel held on the optical axis by a four-vane spider.
The door outline (flat hinge edge, straight sides, 1.15 m corner arcs,
3.18 x 3.10 m) was measured from the `-ADOOR` mesh in NASA's exploded-view
GLB (inch units, Draco-compressed - Blender decodes it). PBR roughness
values are matched to decoded stock textures so the foil does not glint
(see docs/custom-parts.md).

General notes on building KSA parts live in
[docs/custom-parts.md](../../docs/custom-parts.md).

Attachment connectors match the real telescope's appendage locations:

| Connector | Location | Purpose |
|---|---|---|
| `_connector1` | front rim, +X axial | stacking (fairing/door assembly) |
| `_connector2` | aft end, -X axial | stacking (service/propulsion) |
| `_connector3`/`4` | mid-body +/-Y | solar panel masts |
| `_connector5`/`6` | forward shell +/-Z | high-gain antenna masts |

## Files

| File | Role |
|---|---|
| `make_hubble_tube.py` | Blender script generating the mesh atlas + prefab GLBs |
| `make_textures.py` | PIL script generating the diffuse/normal/PBR textures |
| `HubbleTubeGameData.xml` | hand-written gameplay data (mass, editor tags, name) |
| `build/` | generated outputs, packaged into the mod by the csproj |

`build/HubbleTubeAssets.xml` is generated by `tools\PartBundler`, which runs
the game's own `KSA.GlbImport` pipeline from the installed `KSA.dll` - so the
part XML schema always matches the installed game version. Regenerate it
after game updates if parts stop loading.

## Regenerating

```powershell
# 1. Meshes (Blender 3.4+)
& "C:\Program Files\Blender Foundation\Blender 3.4\blender.exe" --background `
    --python parts\hubble\make_hubble_tube.py -- parts\hubble\build

# 2. Textures (Python with Pillow)
python parts\hubble\make_textures.py parts\hubble\build

# 3. Part XML (uses the game's own importer; set KSAGameDir to override)
dotnet run --project tools\PartBundler -- parts\hubble\build

# 4. Validate any hand-edited XML against the game's serializer
dotnet run --project tools\PartBundler -- --validate `
    parts\hubble\build\HubbleTubeAssets.xml parts\hubble\HubbleTubeGameData.xml

# 5. Deploy with the usual mod build
dotnet build src
```

## Pipeline conventions (learned from KSA.GlbImport, game 2026.10.x)

* GLBs store game coordinates directly: +X forward, +Z up, no Y-up
  conversion (`export_yup=False` in Blender).
* The mesh atlas (`<Stem>_MeshAtlas.glb`) holds one named mesh per subpart;
  nodes must be at identity with transforms applied to vertices. Every
  subpart also needs a `<name>_VM` view mesh in the atlas (a watertight,
  usually lower-poly copy): the editor raycasts view meshes for hover, face
  snapping, and connector targeting, and `Part.RayCastEgoSubPart` bails out
  without one - the part loads but nothing can select or snap to it.
* The prefab (`<Stem>_Prefab*.glb`) instances subparts by name + trailing
  number, and declares:
  * `_connector<N>` empties: attachment nodes, +X outward, uniform scale =
    size class (~1 per metre of part diameter).
  * `_ColPrim_Cylinder<N>` (or `Box`/`Sphere`/`Capsule`) empties: colliders;
    for cylinders local Y is the axis, scale X/Z = diameter, Y = length.
    `_ColMesh*` nodes give convex hull colliders instead.
* Textures: `<Stem>_*Diffuse.png`, `*Normal.png`, `*PBR.png`. The PBR map is
  R=ambient occlusion, G=roughness, B=metallic (per
  `Content/Core/Shaders/Common/MaterialSet.glsl`; the community wiki's older
  RoughMetalAo order is outdated).
* Gameplay data (mass, tags, display name) goes in a separate XML patching
  the part with `Modify="Patch"`, mirroring the core `*GameData.xml` files.
